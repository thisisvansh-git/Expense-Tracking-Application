# 💰 Expense & Budget Tracker Application

A modern, responsive, and intuitive personal finance dashboard built using **React**, **HTML5**, **CSS3**, and **JavaScript (ES6+)**. This application helps users track their income and expenses, view net balance calculations in real-time, and manage their personal budget efficiently.

---

## ✨ Features

* **Real-time Balance Calculation:** Automatically updates total income, total expenses, and current net balance as transactions are added or deleted.
* **Transaction Categorization:** Tag transactions with specific categories (e.g., *Salary, Food, Rent, Utilities, Entertainment*).
* **Local Storage Persistence:** All transaction records are saved directly in the browser's `localStorage` so data remains safe upon page refreshes.
* **Data Export:** Export your complete financial transaction log directly to a standard `.csv` file with one click.
* **Modern UI/UX:** Features a sleek dark-mode design, clean card layouts, and responsive components built for all screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/thisisvansh-git/Expense-Tracking-Application.git](https://github.com/thisisvansh-git/Expense-Tracking-Application.git)
2. **Navigate to the project directory:**
   
        Bash
        cd Expense-Tracking-Application
3. **Install dependencies:**

        Bash
        npm install
4. **Start the development server:**

        Bash
        npm run dev
5. **Open your browser and navigate to** http://localhost:5173 **(or the URL displayed in your terminal).**
